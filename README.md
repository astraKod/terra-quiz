# Терра — атлас-викторина

Бесплатная офлайн-викторина по географии: вращающийся глобус, карты материков и России, поиск подсвеченной страны, проверка столицы, флага и координат.

**Сайт:** https://astrakod.github.io/terra-quiz/

## Возможности

- Карты Европы, Азии, России, Африки, Северной и Южной Америки, Океании
- Отдельная карта регионов России (республики, края, области и др.)
- Вращающийся глобус и быстрый переход к нужной карте
- Подсказки при наведении, подписи на карте, авто-увеличение
- Работает без внешних зависимостей во время использования

## Локальный запуск

Откройте `index.html` или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/`.
